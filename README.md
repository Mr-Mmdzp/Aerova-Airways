# ✈️ Aerova Airways

A modern airline website built with HTML, Tailwind CSS, JavaScript, and JSON.

Aerova Airways is a front-end project focused on creating a realistic airline experience with flight search, dynamic flight data, authentication UI, and a clean modern interface.

## ✨ Features

- ✈️ Dynamic flight search
- 🔎 Flight filtering by route and date
- 📋 Flight results generated from JSON data
- 🔐 Login & Register modal
- ✅ Form validation
- 🛫 Services section
- ⭐ Customer reviews
- 📊 About & company statistics
- 📱 Responsive-ready layout
- 🎨 Modern airline-inspired UI

## 🛠️ Built With

- HTML5
- Tailwind CSS
- JavaScript
- JSON
